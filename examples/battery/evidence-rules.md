# Battery evidence rules (demonstration)

This example is a configuration tutorial, not a validated extraction model or scientific database.

Keep machine output at `source_located_not_human_verified`. Check the original source and the following context before accepting a property:

- `composition`
- `capacity_basis`
- `voltage_window`
- `rate`
- `cycle_number`
- `half_or_full_cell`
- `temperature`
- `source_page`

Keep ambiguous or missing context unresolved. Never fill it using the synthetic sample. Material identity and numerical matches are candidates; the listed context is not automatically validated by the extraction engine.
